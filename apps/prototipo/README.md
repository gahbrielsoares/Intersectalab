# Protótipo (apresentação Centelha Fase 3)

Página única que demonstra o fluxo completo do Scientific Chess Method: entrevista guiada, extração de evidências por critério, score calculado por regras (espelho de `packages/scm-engine`) e redação do diagnóstico. Inclui a visão para NITs com benchmark de portfólio.

Roda publicada como Artifact no Claude (usa a capacidade `sample` para a IA). A versão de produção substituirá essas chamadas por um backend próprio com API do LLM.
